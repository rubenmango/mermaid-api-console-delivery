Spec · code

Short bullets. The full list is on Decisions & rules.

  • Keys once: full secret only in the create dialog; masked everywhere else; no reveal.
  • Agent card: Copy prompt only; the prompt reads MERMAID_API_KEY.
  • Credits: allowance first, then one purchased pool; packs 5k / 10k / 15k / custom ×1,000.
  • Roles: members see their share, no admin actions; admins see names and last 4, never secrets.
